# 從興趣找到開源專案：範例與引導方法

這份檔案是**給你（AI 助手）參考的素材**，不是給學生看的清單。目的是在階段 0 聊天時，適時提一個點，幫學生意識到「原來我平常在做的事，背後就有開源專案」。

使用方式：
- **一次只提一個點**，挑最接近學生剛才回答的那個，自然地帶進對話，然後馬上把話題拉回學生自己的生活。
- **不要列出多個領域讓學生挑**，也不要把某個範例的內容整段念給學生聽。
- 學生的興趣不在這份檔案裡很正常。用下面的「引導方法」自己推，這份檔案只是示範推的過程。
- 範例中的專案名稱只是舉例，現況會變。真的要推薦時，照階段 1 的規則確認它有貢獻說明；健康度留給階段 2 檢查。

提點的範例：
> 學生：「我平常會去潛水。」
> 助手：「潛水其實有開源的潛水日誌軟體，可以從潛水電腦匯入紀錄。你每次潛完都怎麼記錄的？」

## 引導方法：興趣 → 痛點 → 想學什麼

大致照這個順序聊。學生在某一層已經講出具體的東西，就可以往下走，不必每一層都問完。

**1. 興趣：從「做什麼」推到「用什麼」**

很多學生說不出自己的興趣跟程式有什麼關係。不要問「你對什麼領域有興趣？」，改問具體的生活：
- 你做這件事的時候會用什麼？App、網站、裝置、紀錄本
- 你會記錄或整理什麼資料？成績、路線、照片、清單、日誌
- 這個圈子的人會分享什麼？譜、地圖、食譜、設定檔，分享的格式和工具常常是開源的

**2. 痛點：有什麼讓你覺得麻煩？**

- 用這些工具時，哪一步最花時間、最想跳過？
- 有沒有某個功能你一直希望它有，但它就是沒有？
- 有沒有看不懂的地方、找不到說明的地方？（這直接對應到文件貢獻）

痛點最容易直接對應到一個 issue，或讓學生發現一個值得貢獻的專案。

**3. 想學什麼：用貢獻來學一個技術**

見下方「想學的技術」一節。能跟興趣結合最好，例如想學 PyTorch 又喜歡吉他，就找音訊 AI 相關的專案。

## 範例

### 🎸 彈吉他、音樂
- **平常會做的事**：看譜（六線譜、和弦譜）、扒歌、錄音、調音、練節奏
- **對應的專案類型**：
  - 樂譜 / 六線譜編輯與顯示：如 MuseScore（大型、活躍的打譜軟體）、TuxGuitar（吉他譜編輯器）、alphaTab（在網頁上顯示吉他譜的函式庫）
  - 音訊分析、AI 扒譜：如 librosa（Python 音訊分析函式庫）、basic-pitch（Spotify 開源的音訊轉 MIDI 模型）
  - 錄音與音訊編輯：如 Audacity
- **可以問學生**：「你扒歌時最花時間的是哪一步？」「你看過最難讀的譜長怎樣？」

### 🤿 潛水
- **平常會做的事**：記潛水日誌（深度、時間、氣瓶）、從潛水電腦下載紀錄、認海洋生物、查潮汐和潛點
- **對應的專案類型**：
  - 潛水日誌軟體：如 Subsurface（支援多種潛水電腦匯入資料的開源潛水日誌）
  - 生物辨識與公民科學：如 iNaturalist（物種觀察平台，部分程式碼開源）
  - 地圖與潛點資料：OpenStreetMap 生態系
- **可以問學生**：「你的潛水電腦資料現在都放哪？」「下水後最想馬上知道什麼？」

### 📷 攝影
- **平常會做的事**：修 RAW 檔、管理照片、加地點標記
- **對應的專案類型**：RAW 處理與相片管理，如 darktable、RawTherapee、digiKam
- **可以問學生**：「你修圖時最常重複做的動作是什麼？」

### 🎮 遊戲
- **平常會做的事**：玩遊戲、做 mod、研究攻略與數據、自己做小遊戲
- **對應的專案類型**：開源遊戲引擎（如 Godot）、開源遊戲（如 OpenTTD、Luanti）、對戰模擬器與數據工具
- **可以問學生**：「你有沒有查過某款遊戲的傷害公式或掉落率？」

### 🏃 跑步、騎車、健身
- **平常會做的事**：記錄路線與配速、分析訓練、看心率
- **對應的專案類型**：運動紀錄 App（如 OpenTracks）、訓練分析（如 GoldenCheetah）、自架運動紀錄平台
- **可以問學生**：「你的運動 App 有哪個數據你很想看但它不給？」

### 🔭 天文、科學
- **對應的專案類型**：星象軟體（如 Stellarium）、科學計算函式庫（如 Astropy）
- **可以問學生**：「你都怎麼查今晚看得到什麼？」

### 🌏 學外語、看動漫、讀日文
- **對應的專案類型**：記憶卡片（如 Anki）、查字典的瀏覽器擴充（如 Yomitan）、字幕與影片播放器（如 mpv）、翻譯專案本身
- **可以問學生**：「你背單字用什麼？哪裡不順手？」這類學生也很適合從**翻譯**開始貢獻

### 🗺️ 旅行、地圖、交通
- **對應的專案類型**：OpenStreetMap 與離線地圖 App（如 OsmAnd、Organic Maps）、大眾運輸資料工具
- **可以問學生**：「你常去的地方，地圖上的資訊正確嗎？」補 OpenStreetMap 資料本身也是一種貢獻

### 📚 閱讀、電子書
- **對應的專案類型**：電子書管理（如 calibre）、電子書閱讀器軟體（如 KOReader）

### ⌨️ 客製化鍵盤、硬體
- **對應的專案類型**：鍵盤韌體（如 QMK、ZMK）、3D 列印切片軟體、智慧家庭（如 Home Assistant）

### 🍳 料理
- **對應的專案類型**：自架食譜管理（如 Mealie、Tandoor Recipes）、食譜格式解析

### 💰 記帳、理財
- **對應的專案類型**：個人記帳軟體（如 Actual Budget、Firefly III）、純文字記帳（如 Beancount）

### 🇹🇼 關心社會議題、在地事務
- **對應的專案類型**：g0v 零時政府的公民科技專案（開放資料、政府資訊視覺化、選舉資料等），可以用中文參與

## 想學的技術 → 怎麼變成貢獻

學生說想學某個技術時，有兩種切入方式：貢獻**那個工具本身**，或貢獻**用它寫成的專案**。大型框架本身通常競爭激烈、review 嚴格，新手從文件、範例、測試切入比較實際；用它寫成的中型專案，比較有機會做到程式碼的貢獻。

- **PyTorch / 機器學習**：PyTorch 本身可以從文件、教學範例、錯誤訊息改善開始；生態系裡的 torchvision、torchaudio，以及 Hugging Face 的 transformers、datasets 也常有文件和範例的需求。更容易上手的是用 PyTorch 寫成的中型專案，例如特定領域的模型庫或工具（音訊、影像、醫療等），可以跟學生的興趣結合
- **React / 前端**：元件庫、文件網站、用 React 寫成的開源 App；無障礙（accessibility）改善也是很好的新手貢獻
- **Rust**：Rust 寫的命令列工具很多，規模適中、測試文化好，適合練習
- **後端 / API**：Web 框架的外掛、自架服務類的開源專案（記帳、食譜、相簿等，見上方範例）
- **想練寫測試**：找有測試框架、但覆蓋率不高的專案（見 `contribution-types.md` 的補測試一節）
- **想熟悉大型專案的協作**：找有完整新手計畫、貢獻者指南寫得很詳細的大專案，但要先讓學生有心理準備：review 會比較慢

## 學生說「我沒什麼興趣」的時候

很常見，不要逼他。改從這幾個方向問：
- 「你手機裡最常開的五個 App 是什麼？」
- 「你寫作業或專案時用了哪些套件或工具？」（requirements.txt、package.json 裡的套件都是候選）
- 「最近有什麼軟體讓你覺得很煩？」
- 「你想畢業後做什麼工作（或現在在做什麼）？」反推那個領域常用的開源工具
